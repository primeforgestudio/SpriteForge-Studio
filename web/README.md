# SpriteForge Studio (Web Edition)

Клиентское веб-приложение для сборки спрайт-атласов из видео/PNG-секвенций и пакетной обработки PNG-спрайтов. 

**100% Client-Side:** Не требует установки Python, PySide6, OpenCV, PyAV или ffmpeg. Работает целиком в браузере (Chrome, Safari, Edge, Firefox), файлы никуда не загружаются и обрабатываются локально на GPU/CPU.

---

## Возможности

### Режим Atlas
- Загрузка видео (**MP4, WebM, MOV, AVI**) или **PNG-секвенций** через drag & drop или диалог выбора.
- **Интерактивный таймлайн**:
  - Обрезка диапазона (In/Out markers);
  - Ромбики ключевых кадров: равномерное распределение по числу кадров («Distribute Keys») либо ручное перетаскивание ключа на любой кадр;
  - Скраббинг, воспроизведение (Space), пошаговый переход (стрелки), выбор FPS (12, 24, 30, 60).
- **Продвинутый Chroma Key**:
  - Пипетка (Eyedropper) для выбора цвета прямо из кадра;
  - Gain (Hue tolerance), Soften (размытие маски), Clip (гамма/контрастность маски);
  - Защита по насыщенности (Sat Prot) и яркости (Val Prot);
  - Субпиксельный Erode и размытие альфа-контура.
- **Вьюпорт**:
  - Zoom (колесо мыши), Pan (перетаскивание левой/средней кнопкой);
  - Фоны: шахматка (прозрачность), черный, белый, пресеты, кастомный цвет.
- **Экспорт**:
  - `atlas.png` (чистый PNG со склеенной сеткой);
  - `atlas.json` (метаданные с индексами кадров, координатами и размерами ячеек для Godot/Unity).

### Режим Sprites
- Пакетная загрузка набора PNG-файлов.
- Индивидуальная или глобальная трансформация: масштаб (Scale), смещение (Offset X/Y).
- Подгонка под целевой аспект (Crop/Resize).
- Наложение на цветной фон или сохранение с прозрачностью.
- Пакетный экспорт в **`.zip`** архив с гибким переименованием (`prefix_0001.png`).

### Сохранение настроек
- Автоматическое сохранение параметров в `localStorage`.
- Экспорт и импорт `settings.json` (полная совместимость с конфигурациями десктопной версии SpriteForge Studio).

## Запуск и разработка

### Локальный запуск dev-сервера:
```bash
cd web
npm install
npm run dev
```

### Сборка готовой версии (Production Build):
```bash
npm run build
```
Готовые статические файлы будут в папке `dist/` (суммарный вес бандла — менее 300 КБ!).

### Деплой
Так как приложение чисто статическое, его можно выложить бесплатно в один клик:
- **GitHub Pages** (достаточно запушить папку `dist`);
- **Vercel** (`npx vercel`);
- **Netlify** (перетащить папку `dist` в дашборд);
- Либо запустить локально через любой статический сервер (`npx serve dist` или расширение Live Server в VS Code).
